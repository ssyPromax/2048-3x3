# 2048 (3x3) 控制台版

3x3 棋盘的 2048 小游戏，C++ 编写，Windows 控制台运行。

## 玩法

- 使用**方向键**或 **W / A / S / D** 移动方块
- 相同数字碰撞时合并，每次合并得到相应分数
- 棋盘填满且无法移动时游戏结束，按 **R** 重开
- 合成 **2048** 即获胜（可继续挑战高分）
- 按 **Q** 随时退出

## 编译

需要 MinGW-w64 (g++)：

```bash
g++ -O2 -static -mconsole -o 2048.exe 2048.cpp
```

`-static` 表示静态链接，生成的 exe 无需额外 DLL 即可在任何 Windows 上直接运行。
