# 2048 (3x3)

3x3 棋盘的 2048 小游戏，C++ 编写，提供**图形界面版**和**控制台版**两个版本，Windows 直接运行。

## 玩法

- 使用**方向键**或 **W / A / S / D** 移动方块
- 相同数字碰撞时合并，每次合并得到相应分数
- 棋盘填满且无法移动时游戏结束，按 **R** 重开
- 合成 **2048** 即获胜（可继续挑战高分）

## 图形界面版（推荐）

标准 Windows 窗口，经典 2048 配色，双缓冲绘制无闪烁。

```bash
g++ -O2 -static -mwindows -o 2048gui.exe 2048gui.cpp
```

操作：方向键 / WASD 移动，R 重开，Esc 退出。

## 控制台版

在终端里玩的轻量版本，适合远程或无桌面环境。

```bash
g++ -O2 -static -mconsole -o 2048.exe 2048.cpp
```

操作：方向键 / WASD 移动，Q 退出；游戏结束后按 R 重开。

两个版本都使用 `-static` 静态链接，生成的 exe 无需额外 DLL 即可在任何 Windows 上直接运行。
